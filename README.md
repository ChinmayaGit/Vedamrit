# Vedamrit

A Flutter reading app for the Bhagavad Gita, the four Vedas, and Srimad Bhagavatam, laid out like a book app: a verse of the day, a book of the day, and a place to continue.

Shlokas come from the [Bhagavad Gita API](https://vedicscriptures.github.io/). Sanskrit, Hindi, and English include the acharya voices that API publishes. Telugu, Tamil, Malayalam, and the other reading languages are a machine reading aid from [MyMemory](https://mymemory.translated.net/), saved on the phone after the first load.

Full books are searched on [Project Gutenberg](https://gutendex.com/), [Open Library](https://openlibrary.org/developers/api), and the [Internet Archive](https://archive.org/developers/). The download button keeps a public file on the phone.

Sangha (thoughts, circles, channels, chat) and the temple history feed stay on this phone.

## Run

```bash
flutter pub get
flutter run
```
